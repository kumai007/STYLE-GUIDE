# hf-engine (gx HyperFrames engine)

- `parts/<id>/` is GENERATED by `node build.mjs <id>` from `cases/<id>.mjs` + `devices/*.mjs`. Never hand-edit `parts/`.
- Past-project learnings: `docs/knowledge/README.md`.
- Notes from Final Phase Lite (`[Sent from Final Phase Lite]`, opened by `tools/case-build/preview.sh`): the note's
  part = `parts/<id>`. Open the frame picture, change only what the note asks, in `cases/<id>.mjs` (or the device),
  then run `node build.mjs <id>`. The window reloads by itself. Do not render: the final render runs on GitHub.
- `cases/` holds only templates (2026-11-18): coc_case09 (base: raws, pages, boards), coc_case05 (footage only),
  coc_case25 (tracked blur), coc_case08 (silent CCTV), coc_intro. Their coc2h-vol1 media/paths are deleted: copy the
  structure into a new `cases/<id>.mjs`, do not build them as-is. `media/<prod>` = media root for new builds.
- Same look rules as always (style guide, SOPs, playbook). Never read `media/` (13 GB) or `v*_stills/`.
