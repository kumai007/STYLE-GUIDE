# kw family (Kyle Ward van-camping per-video overlays)

Remotion source: `templates/src/presets/kw/FrameCircle.tsx`, `AudioWave.tsx`; registrations in `templates/src/Root.tsx`
(folders KW-Case1..8). 44 compositions = 24 FrameCircle + 20 AudioWave, 1920x1080 @ 30000/1001 (NTSC 29.97).
All 44 have a props file `props/kw/<ID>.json` (generated by `tools/kw-gen-props.py` from Root.tsx; re-run if Root.tsx changes).

## Templates (both Native: HTML + SVG + GSAP, no hosted code)

### compositions/kw/frame-circle.html  (FrameCircle)
Evidence still pushed in slowly + GN-kit red circle that draws on. Ring is parented to the image (rides the push).
Variables (Remotion names/defaults): `image` string "highlights/kw-c1-figure.png" (legacy `highlights/x.png` accepted, resolved to
`assets/kw/x.png`), `cx` 900, `cy` 520, `d` 500, `drawAt` 0.6 s, `startScale` 1.0, `endScale` 1.12,
`layer` all|image|circle, `durationInFrames` 150 (Remotion keeps this on the Composition; here it is a variable).
Layers: `all` and `image` = opaque black bg -> render **mp4**; `circle` = transparent -> render **mov** (ProRes 4444, yuva).
Easing = exact Remotion bezier(0.25,0,0.15,1) implemented in `lib/kw-common.js` (GSAP ease function, no CustomEase plugin).

### compositions/kw/audio-wave.html  (AudioWave) - always **mov** (transparent)
Variables: `data` "kw/waves/c1_k1.json" (only the basename is used), `width` 1024, `maxHeight` 120, `cy` 540, `color` #F10410,
`durationInFrames` 925. 64 bands mirrored left/right of centre, centre line, 8-frame fade in/out, drop shadow.
Source used useState/useEffect/delayRender + fetch (lint blocker). Port: the per-frame spectra were ALREADY precomputed in
`templates/public/kw/waves/*.json` ({fps, frames, bands[frame][64]}); `tools/kw-waves-build.mjs` bundles all 20 into
`assets/kw/waves/all.js` (`window.KW_WAVES`, 2.16 MB) loaded by a plain synchronous `<script src>`. Nothing is fetched or computed
at seek time; the bars are a pure function of timeline time (frame = floor(t*fps)), applied from a tween onUpdate.
Not ported: the generator that made those JSONs from audio (`.raw-editor/wave_env.py`, deleted in the 2026-10-24 clean-up). New
audio would need a new analyser that emits the same JSON schema, then re-run `kw-waves-build.mjs`.

## Render
Length comes from `durationInFrames`: the composition script writes root `data-duration` from the variable at init (verified:
KW8-ClockCircle -> 52 frames, KW1-Wave1 -> 925, KW5-Wave1c -> 25). No wrapper needed for length.
`--variables-file`, `--variables -` (stdin) and `--variables <path>` are all broken in 0.8.210 ("io.readFile / io.readStdin is not a
function"). Use the wrapper (inlines the JSON, quotes it for cmd.exe, picks mp4/mov from the output extension, -w 2):

    node tools/kw-render.mjs compositions/kw/frame-circle.html props/kw/KW1-FigureImg.json    out/kw/KW1-FigureImg.mp4
    node tools/kw-render.mjs compositions/kw/frame-circle.html props/kw/KW1-FigureCircle.json out/kw/KW1-FigureCircle.mov
    node tools/kw-render.mjs compositions/kw/audio-wave.html   props/kw/KW8-Wave2a.json      out/kw/KW8-Wave2a.mov

Layers `image`/`all` -> use .mp4; `circle` and all waves -> .mov. Confirmed with ffprobe: mov = yuva444p12le, 30000/1001, correct nb_frames.
`hyperframes lint` on both files: 0 errors, 0 warnings.
