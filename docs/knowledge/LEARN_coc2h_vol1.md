## Devices + look recipes that worked
- Per-case recipe (copy for every case): berg card 0-4.8/4.97 s (BergX fades from black 0-30 f, zoom 1.00-1.06, white title shadowed, one soft fade) -> 24 f dissolve into first shot; footage via CFoot (v8 grade + eased 3-D move); raws via CFoot raw (gentle push); pages = Paper + 5 PaperMv moves cycled; red #E0282A MarkW sweep; boards/freezes SBoard/SFz; Tex grain over every non-raw stretch (none on raws, ramped over dissolves); AbyGrade top layer whole part (src: cases/coc_case09.mjs l.1-4, coc_case01.mjs l.337-349).
- Shot plan format `[anchor phrase, spec]` per VO: each shot starts on the word onset of its anchor; spec kinds f/ftg (footage), fz (plays ~75 f then dissolves to B&W print), pg (page + mk=[first,last] spoken words), bd (board hero+items), place line, stamp/clock; this plan style replaced the per-row shots.json style after case 5 (src: cases/coc_case06.mjs l.82-139, coc_case05.mjs l.54).
- Page marker = longest >=3-word run of the VO inside the page's key sentence; null = zoom only; foreign-language pages (Arabic c07, Slovak/Czech c13) mark the key sentence while the VO says its translation; a page whose time disagrees with the VO (P3 4:30 vs VO 4:18) is never marked (src: cases/coc_case01.mjs l.178-179, coc_case07.mjs l.137, coc_case13.mjs l.155).
- Page art: `pages/art/<id>.png` = real headline capture joined above body crop via `tools_v9/compose_heads.py` (reads the case's table of page text lines, `J.lines`); missing capture -> alt spec (footage/board) so a case still builds (src: cases/coc_case01.mjs l.163, coc_case15.mjs l.115).
- Private-name mosaic = 24 frame-px blocks baked into a data: PNG at build time (bbox padded 6 page px); boxes straddling the headline cut are clipped not dropped (dropping left half a face/name unblurred, found in case 9) (src: cases/coc_case01.mjs l.150, coc_case09.mjs l.139; tools/case-build/test_lint_vo.py l.17).
- Map/print boards: board camera templates [f,cx,cy,z] on a 5400x3200 board; neighbouring prints from different cameras (interleave MPD, SWFA, MPD3); hero alternates page crop / freeze, never the previous board's hero; hero slides in with 100 f settle while 3-D yaw eases flat (src: cases/coc_case01.mjs l.228,267-286).
- Date count-in over a burned-in stamp: overlay must hold >= 3.5 s and end on the hard cut into the raw; moved bottom-right off the stamp row (src: cases/coc_case01.mjs l.463).
- Flat push (no 3-D) wherever marks/rings sit on footage, else the 3-D move slides the mark off target; ring cases c02 cue_10, c03 galley, c16 (src: cases/coc_case01.mjs l.455, coc_case02.mjs l.393, coc_case03.mjs l.195).
- Low-res / odd sources: 9:16 -> 'fit' = centred + CFoot blur fill (c07 480x848, c17 576x1024, c23 4:3); wide crops only so upscale stays clean (c21 658x480 "never tighter than 1.25x"); pillarboxed picture cropped to its column (c18 x72-522, c12 x436-844) (src: cases/coc_case07.mjs l.5, coc_case21.mjs l.47, coc_case18.mjs l.4).
- Single short source (<=70 s: c09, c17, c23, c27): reuse via slowed replays (sp), freezes, boards, pages; split any non-page shot > 8.5 s at the comma nearest the middle into a second alternate visual (src: cases/coc_case09.mjs l.5-7, coc_case02.mjs l.300).
- 4-camera CCTV grid (c08 CGS 1280x592 2x2, 6 fps): crop per grid square, positions measured by code; left/right channel order by position only, never as text (src: cases/coc_case08.mjs l.4,20).
- 6 fps CCTV (c15 FPD, 206 frames): stills = native frame n = round(t*6); reads never past last native frame; cut camera stamp off (hour disputed between sources) (src: cases/coc_case15.mjs l.4-5,25).
- Outro: no text on the berg, last 7.75 s clean for YouTube end-screen elements, no subscribe/bell, no invented graphics, dip to black last 2.5 s with music tail; calmer moves (rot <= 3 deg, zoom 1.08-1.13, pan <= 1 %; scale >= 1.08 keeps frame edge out) (src: cases/coc_outro.mjs l.1-8,21-22).
- Intro wall: 28 distinct tiles (16 live, 12 freezes), 480x270 tiles, gap 40, plane 3860x1200, 50 f tile entries every 3.5 f (all in by 2.2 s), every tile on screen >= 64 f; one pan curve + overlapping log-zoom (1.45 -> 0.56 by 170 f -> 4.0 dive by 256 f); safe picks: no person struck, LSV only >= 413 s, private faces blurred (src: cases/coc_intro.mjs l.58-77).
- Intro berg title: upper berg + waterline 0-36 f, one long sym-eased descent 36-196 f, title soft-fades in the sea on "and we stop" (198-234 f), holds 3.6 s; ends on LAPD teaser dipping to black over last 0.9 s so case 1 opens on black (src: cases/coc_intro.mjs l.106-135).
- 3-D move set: Mv [scale, rotX, rotY, tx%, ty%], perspective 1800 px, rot 3-5 deg easing to 0 while zoom 1.10-1.17 and pan 1-1.5 %, cover-checked; ease alternates io (0.35,0,0.25,1) / sym (0.42,0,0.58,1); no two adjacent shots share a direction (src: cases/coc_intro.mjs l.20-22).

## Audio + VO
- Loudness references (all cases): VO = -28.3 LUFS short-term median while talking (I -27.7); music = VO ref -11 LU = -39.3 LUFS short-term, -3 LU more under raws (raw shot minus VO windows, 0.5 s ramps); SFX = VO ref -14 LU = -42.3 LUFS (cases) / -11 LU (intro/case 1 v8); SFX never above the music; raws -29 LUFS integrated per window (just under VO, within +-3 LU) (src: cases/coc_case01.mjs l.329-330,485-508; coc_case06.mjs l.79; coc_case09.mjs l.53).
- Music levelling code ("musLane"): lane gain every 0.5 s = target - bed's own ebur128 short-term (3 s centred, power-mean smoothed +-2 s), clamped -24..+12 dB (HyperFrames max gain +12 dB) so bed has no holes; 3 s crossfades between beds (src: cases/coc_case01.mjs l.485-488, coc_intro.mjs l.43-44).
- Bed rotation per case: bed = music(8,9,10) by NN mod 3, start offset NN*37 mod 200 s, then next bed from 0 with 3 s crossfade; ensure bed length >= remaining (music9 303.8 s, music10 300.9 s) (src: cases/coc_case05.mjs l.252, coc_case07.mjs l.309).
- Silent raws policy was applied two ways: music OUT (0.5 s ramps) under silent raws (c8,11,12,14,15 = master SOP "never music over a silent raw") vs bed kept 3 dB lower (c7,13,21,23, case-1 rule). Pick one in the SOP (src: cases/coc_case07.mjs l.309-311, coc_case14.mjs l.297, coc_case21.mjs l.271).
- Silent CCTV raws get synthetic room tone: brown noise, gain .045 (~ -50 LUFS), 0.3 s fades, chained 0.3 s overlap every 30 s (c8); c20 own traffic bed (Epidemic) -32 LUFS + own impact hit; c14 synthetic road ambience; c11 "needs licensed ambience SFX" = open issue; no night/ambience SFX exist in K library (src: cases/coc_case08.mjs l.303, coc_case20.mjs l.241, coc_case11.mjs l.323, coc_case15.mjs l.6-8).
- Ambience under a raw: in under VO (ducked -24 dB), full after VO ends, out exactly at raw end (c4 wind+rain I -7.1 LUFS kept at -36 LUFS alone); c18 cabin ambience = source's own speech-free window at -38 LUFS, 0.6 s fades (src: cases/coc_case04.mjs l.256-267, coc_case18.mjs l.319).
- Bleeps = mute + 1 kHz tone, written in the sub with a dash; raw sound muted after `cut` source second so a scream/line is never heard twice (c28 R1 stops 6.0, R2 19.0); subs only where hand-checked (c28 job quotes on first burst only, not ear-checked) (src: cases/coc_case09.mjs l.40,299; coc_case28.mjs l.43-44).
- Whisper on farm: medium.en for most, small.en for AA (594x328), large-v3 cross-check for CFK; job.json cue times were approximate ("This is what we came for" at 23.2-25.4, not 30) -> always re-cut raws on word edges; raws start/end on word edges (src: cases/coc_case17.mjs l.8-9, coc_case12.mjs l.48).
- Burst detection for scream-only raws: silencedetect with 300 Hz high-pass at -32 dB (c28) (src: cases/coc_case28.mjs l.42).
- Master loudness: join.sh only limits TP to -1.05; `master_loudness.sh` = one static gain to -16 LUFS +-0.5, alimiter, TP <= -1.5, retries up to 6 (full video took 3 tries: -16.2 LUFS, TP -1.8 then ok, 26 min incl. move; case-1 sample -16.2 / -2.3 dBTP); if limiter works hard, lower music/SFX in the part mix instead (src: case-work/coc2h-vol1/master_loudness.sh, FARM_FIX.md).
- Re-recorded lines: vo_035, 044, 051, 073, 081 (final take 127.11 s), 109, 143, 152; old takes kept in narration/raw/_old081, _oldvo_035, _oldvo_044 (src: productions/coc2h-vol1/vo_*.csv, TIMELINE sec 4).
